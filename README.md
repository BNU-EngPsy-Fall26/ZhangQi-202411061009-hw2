# 实验 1 · 非注意盲：意外刺激的形象 × 速度 × 轮次

## 1.1 实验说明

**原范式** Simons 与 Chabris（1999）的持续非注意盲范式。被试观看 15 秒传球动画
（警长队与巫医队各 4 名球员持续移动并队内传球），任务是默数指定球队的传球次数。
在注意力被主任务占据的条件下，视野中央出现的显著意外物体常被完全忽略。

**新增条件** 原范式每名被试仅经历一次关键试次，无法考察意外刺激特征的作用。
本实验改为**每一正式轮次均呈现一个意外刺激**，并系统操纵三个变量：
刺激形象（白色雨伞 / 手持金币的鹅 / 胸口佩枫叶徽章的鹅）、运动速度（400 px/s / 110 px/s / 静止 4 s）、
呈现方向（左右横穿 / 上下竖穿，随机）。后两种形象与被注意球员同属鹅类，
用于检验注意定势（attentional set）的作用；雨伞为无关类别的高对比刺激。

- **自变量**：刺激形象（3）× 运动速度（3）× 轮次（1–6）
- **因变量**：① 察觉率（是否看到异常物体的二分报告）；② 迫选正确率（物体身份、鹅的特征、屏幕区域、运动方向）；③ 计数误差
- **设计**：被试内。每人 1 轮练习（无刺激）+ 6 轮正式（每轮 1 个刺激，15 s）。
  平衡：每种形象 2 次、每种速度 2 次，同一形象两次速度必不同，同一形象不出现于相邻轮次；
  出现时刻（3–7 s）、方向、两队传球速度（375–600 px/s）逐轮随机。

**数据来源** 10 名被试，60 个关键试次（每人 6 轮）。

## 1.2 预期结果

1. 速度主效应：快速 > 慢速 ≈ 静止。依据 Wallisch 等（2023）的 4493 人大样本研究，
   快速运动而非物理显著性打破非注意盲；慢速物体在屏上停留更久却更少被察觉。
2. 形象主效应：与被注意球员同类的鹅形刺激察觉率 ≥ 无关的雨伞。依据 Most 等（2005）的注意定势假设，
   以及 Simons 与 Chabris（1999）中注意黑队时大猩猩察觉率（58%）高于注意白队（27%）的相似性效应。
3. 速度 × 形象交互：雨伞（异类）的速度斜率应陡于鹅形（同类）。依据 Wallisch 等（2023）
   在不匹配注意集条件下观察到的更陡速度斜率。
4. 轮次效应：察觉率随轮次上升——被试意识到可能存在的异常物体后主动分配注意资源。
5. 迫选：察觉者四类迫选正确率均高于随机水平（25% / 25% / 25% / 20%）。
6. 眼动：注视已接触刺激邻域却报告未察觉的现象应存在（"注视 ≠ 知觉"）。

## 1.3 实际结果

**描述统计** 总体察觉率为 85%（51/60）。三种速度条件下察觉率分别为
快速 95%、慢速 75%、静止 85%；三种形象条件下分别为雨伞 90%、金币鹅 90%、枫叶鹅 75%。
逐轮察觉率：第 1 轮 90%、第 2 轮 80%、第 3 轮 80%、第 4 轮 100%、第 5 轮 80%、第 6 轮 80%。
平均计数误差 0.52 次。

**推断检验** 以每名被试在各条件下是否至少察觉一次为指标进行 Cochran's *Q* 检验。
速度条件差异不显著，*Q*(2) = 2.00，*p* = .368；形象条件差异不显著，*Q*(2) = 2.00，*p* = .368；
轮次差异不显著，*Q*(5) = 2.56，*p* = .767。

**迫选** 身份迫选正确率 96.1%（49/51），显著高于随机水平（25%），*p* < .001；
特征迫选 78.8%（26/33），*p* < .001；方向迫选 98.0%（50/51），*p* < .001；
区域迫选 27.5%（14/51），与随机水平无差异，*p* = .394。

**眼动** 有效眼动样本仅 8 个试次（察觉 6 / 未察觉 2），
注视接触率差异不显著，*t*(4.10) = 0.11，*p* = .460，*d* = 0.06，因样本过小不作推断。

## 1.4 讨论

速度主效应未达显著，与 Wallisch 等（2023）的预测方向一致但效应量不足以在当前样本下检出。
需注意本实验存在**天花板效应**：总体察觉率 85% 远高于原范式报告的约 50%。
主要原因有三：其一，意外刺激（伞高 74 px、鹅高 116 px）相对 900 × 600 画布占比远大于原研究中的行人大猩猩；
其二，逐轮重复呈现使被试在第 2 轮起即形成预期，削弱了"非注意盲"赖以成立的意外性；
其三，被试通过链接自行在安静环境完成，注视稳定性可能优于实验室集体观看。

区域迫选正确率仅 27.5%，接近随机水平，说明被试虽能识别物体是什么、怎么动的，
却难以回忆其空间位置——这一分离模式与"物体识别依赖注意、空间位置编码更依赖情境绑定"的解释一致，
也提示该指标可能不适合作为察觉真实性的判据。

后续改进建议：缩小意外刺激至与球员等大以下、延长单轮时长以稀释预期、
或在被试间设计中仅呈现一次关键试次以获得更高的盲视基线。

# 实验 2 · 情绪 Flanker：干扰项的情绪价效

## 2.1 实验说明

**原范式** Eriksen 与 Eriksen（1974）的侧翼干扰范式。屏幕中央呈现指向左或右的目标箭头，
两侧各呈现两个干扰箭头；被试仅判断中央箭头方向。干扰项与目标方向不一致时反应时延长，
反映抑制无关信息所需的认知控制代价。

**新增条件** 将干扰箭头替换为携带方向箭头的灰度人脸照片（2 张愤怒男面孔、2 张中性男面孔，
经亮度加权灰度化以匹配低层视觉属性）。愤怒面孔能否比中性面孔产生更大干扰，文献结论不一：
可能因威胁刺激的加工优先权而增大干扰，也可能因情绪与任务无关而被忽略，或如 Fenske 与 Eastwood（2003）
所报告因负性情绪收缩注意范围反而减小干扰。

- **自变量**：侧翼面孔情绪（愤怒 / 中性）× 一致性（一致 / 不一致）
- **因变量**：① 正确试次反应时；② 正确率；③ 冲突量（不一致减一致）
- **设计**：2 × 2 被试内。每人 16 个练习试次 + 80 个正式试次（每格 10 次，方向各半，随机混排）。
  中央目标无面孔，仅侧翼携带情绪信息。

**数据来源** 10 名被试，800 个正式试次。

## 2.2 预期结果

三个竞争假设由数据裁决：

1. **威胁捕获假设**：愤怒侧翼冲突量 > 中性侧翼，增量约 5–20 ms。
   任务无关条件下情绪面孔的捕获效应通常较小（Barratt & Bundesen, 2012）。
2. **冷注意假设**：增量 ≈ 0，冲突量完全由箭头一致性决定。
3. **注意收缩假设**：增量 < 0，负性情绪收窄注意范围从而减小侧翼效应（Fenske & Eastwood, 2003）。

另预测愤怒侧翼区域注视占比高于中性侧翼条件。

## 2.3 实际结果

**描述统计** 四条件平均反应时（正确试次）：中性·一致 452.74 ms、中性·不一致 478.73 ms、
愤怒·一致 454.27 ms、愤怒·不一致 496.12 ms。总体正确率 94.5%。
中性侧翼冲突量 25.99 ms，愤怒侧翼冲突量 41.85 ms，情绪干扰增量 +15.86 ms。

**推断检验** 对 10 名被试的冲突量作配对样本 *t* 检验。
情绪干扰增量未达显著，*t*(9) = 0.72，*p* = .246，Cohen's *d*<sub>z</sub> = 0.23。
经典 Flanker 效应（不一致减一致）显著，*M* = 34.1 ms，*t*(9) = 3.42，*p* = .004，*d*<sub>z</sub> = 1.08，
落在 Eriksen 与 Eriksen（1974）报告的 20–60 ms 区间内。

## 2.4 讨论

经典侧翼效应稳健复现（34.1 ms，*d*<sub>z</sub> = 1.08，大效应量），
说明冲突抑制机制被成功诱发，范式有效。

情绪干扰增量方向符合威胁捕获假设（+15.9 ms，正落在预注册的 5–20 ms 区间内）但未达统计显著，
*dz* = 0.23 为小效应。三种竞争假设中，数据最支持**冷注意假设**：
在与任务无关的情绪侧翼条件下，情绪信息未能稳定地占用认知控制资源。
这一结果与 Barratt 与 Bundesen（2012）的发现一致——情绪面孔的注意捕获依任务相关性而定。

值得注意的是，个体差异极大：10 名被试中 4 人的愤怒侧翼冲突量超过 60 ms，
而 3 人呈负值（愤怒侧翼冲突小于中性）。这种方向上的个体差异提示情绪干扰可能受
状态焦虑、面孔加工策略等个体变量调节，未来研究应纳入个体差异量表。

统计功效方面，以 *dz* = 0.23 计，达到 80% 功效需约 150 名被试，
远超本作业规模。因此当前的不显著结果不能作为否定威胁捕获假设的证据，只能说明效应量在此设计下偏小。

# 实验 3 · 图形比例估计：呈现时长与编码类型

## 3.1 实验说明

**原范式** Cleveland 与 McGill（1984）的图形知觉层级范式。被试估计统计图形中
某一部分占整体的比例，四类编码分别为位置（标尺填充至刻度）、长度（两条线段之比）、
角度（圆中扇区展开角度）、面积（同心圆面积比）。经典结果给出准确性层级：
位置 > 长度 > 角度 > 面积。<br>

**新增条件** 引入**呈现时长压力**。部分试次的图形仅呈现 500 ms 或 2 s，
随即被随机噪点掩蔽 300 ms，阻断事后心理表象的逐步推算；另一部分不限时。
若层级源于自动的知觉编码，则短时条件下位置/长度的优势应保持而角度/面积恶化更剧；
若层级源于可控制的认知计算，则短时条件下各编码差异应缩小甚至反转
（Moreira 等，2024 报告偶发性呈现下角度反而最准）。

- **自变量**：图形编码（位置 / 长度 / 角度 / 面积）× 呈现时长（500 ms / 2 s / 无限）
- **因变量**：① 估计百分比（0–100 滑块）；② log₂ 误差（Cleveland & McGill, 1984 原记分）；③ 绝对百分比误差
- **设计**：4 × 3 被试内。每人 8 个练习试次 + 96 个正式试次（每格 8 次，
  长度编码的蓝条上下位置在重复轮次中互换以消除位置偏好）。

**数据来源** 10 名被试，960 个正式试次。

## 3.2 预期结果

1. 编码主效应：位置与长度误差最小，面积误差最大。
   角度在层级中的位置存在争议（Heer & Bostock, 2010；本班课堂数据亦显示面积优于角度）。
2. **编码 × 时长交互（核心检验）**：短呈现条件下"需计算"的编码（角度、面积）
   误差增量应大于"自动"编码（位置、长度），支持自动性假设。
3. 呈现时长主效应：500 ms 误差大于无限时条件，但 500 ms 与 2 s 之间差异预计有限。
4. 人机对比：多模态大模型不受呈现时长限制，其编码误差排序应与人类不同。

## 3.3 实际结果

**描述统计** 各编码 log₂ 误差：位置 0.21、长度 0.23、角度 0.20、面积 0.37。
绝对百分比误差：位置 6.63%、长度 6.48%、角度 7.35%、面积 13.85%。
各呈现时长 log₂ 误差：500 ms 0.27、2 s 0.25、无限 0.24。

**编码 × 时长交叉表**（log₂ 误差）

| 编码 | 500 ms | 2 s | 无限 |
|---|---|---|---|
| 位置 | 0.21 | 0.19 | 0.21 |
| 长度 | 0.26 | 0.24 | 0.18 |
| 角度 | 0.21 | 0.19 | 0.20 |
| 面积 | 0.39 | 0.37 | 0.36 |

**推断检验** 编码主效应显著，Friedman χ²(3) = 16.92，*p* < .001，Kendall's *W* = 0.56。
实测层级为角度（0.20）< 位置（0.21）< 长度（0.23）< 面积（0.37）。
编码 × 时长交互未达显著，*t*(9) = −0.78，*p* = .229，*d*<sub>z</sub> = −0.25，
角度/面积的短时惩罚（*M* = 0.02）与位置/长度的短时惩罚（*M* = 0.04）无可靠差异。
呈现时长主效应边缘显著，*t*(9) = 1.77，*p* = .055，*d*<sub>z</sub> = 0.56，
500 ms 与无限时条件相差 0.028 log₂。

## 3.4 讨论

编码主效应稳健（*W* = 0.56，中等强度一致性），但**实测层级与经典结果部分不符**：
面积如预期最差（0.37，为其余编码的 1.6–1.9 倍），但**角度反而最优**，
位置与长度居中且彼此接近。这一模式与 Moreira 等（2024）在偶发性短呈现下
观察到"角度最准、点位置最差"的反转现象方向一致，提示 C&M 层级可能依赖特定的呈现条件与判断方式，
并非普遍恒定的知觉常量。本实验的角度编码为整圆中的扇区，边界清晰且以 12 点为锚，
可能比原研究中分散的线段角度更易判断。

核心的编码 × 时长交互未成立，短时条件下"需计算"编码并未恶化更剧。
结合时长主效应仅边缘显著（*dz* = 0.56，0.028 log₂），可推测本实验的时长操纵强度不足：
2 s 已足以完成对四类编码的知觉提取，噪点掩蔽虽阻断表象持续，
但被试在刺激呈现期间即可形成足够精确的比例估计。此外，滑块作答不限时，
被试可在掩蔽后依据残余印象反复调整，进一步削弱了时长效应。

后续改进建议：将中时长条件改为 1 s 以内、缩短滑块可调整窗口（如 1.5 s 强制提交）、
并增加逐试次作答时间的记录以量化决策过程。

# 人类与大模型对比（实验 3 扩展）

## 4.1 方法

将实验 3 的 16 个唯一刺激图（4 编码 × 4 比例）以**匿名文件名**（Q01–Q16）分发给两个多模态
大语言模型独立作答，要求仅凭图像输出 0–100 的整数估计，禁止访问真值与彼此答案。
模型：GLM-5.3、Grok-4.7。两模型逐题一致（平均绝对差 4.8 个百分点，10/16 题差异 ≤ 5）。

第三个模型（Kimi-K3）在同一协议下将 75% 填充报告为"很小"，
log₂ 误差均值达 1.00 且自评置信区间与实际偏差严重脱节，判为无效评估，如实记录于
`ai/ai_results.json` 的 `protocol` 字段，不计入正式结果。

## 4.2 结果与讨论

两模型的编码误差排序均为**角度最优**（与人类实测一致），但位置与长度的排序不同：
GLM-5.3 为角度 < 位置 < 长度 < 面积；Grok-4.7 为角度 < 位置 < 面积 < 长度。
与人类一致的是面积最差，与人类不一致的是长度——人类长度与位置接近，两模型则将其排在末位。

人类与模型共享"角度易、面积难"的模式，提示这两端可能反映编码本身的信息效率而非人类特有偏差；
分歧集中在中间编码，可能源于模型对线段长度缺乏稳定的像素级度量能力。
本对比受样本限制（仅 16 题、单次作答），结论应视为方向性观察。
