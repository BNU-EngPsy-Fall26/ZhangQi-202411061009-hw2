实验 1 · 非注意盲

自变量：物体形象（雨伞 / 金币鹅 / 枫叶鹅）× 速度（快 / 慢 / 静止）× 轮次　 因变量：察觉率 + 迫选正确率　 设计：被试内，每人 6 轮　 误差条 = ±1 SE

实验 2 · 情绪 Flanker

自变量：侧翼情绪（愤怒 vs 中性）× 一致性　 因变量：反应时 / 正确率 / 冲突量　 设计：2×2 被试内　 误差条 = ±1 SE

实验 3 · 图形比例估计

自变量：编码类型（位置 / 长度 / 角度 / 面积）× 呈现时长（500ms / 2s / 无限）　 因变量：估计百分比与 log₂ 误差　 设计：4×3 被试内　 误差条 = ±1 SE
